# ✨ Cinematic Video Audio Replacer

A Streamlit web app for replacing a video's original audio with a new soundtrack using FFmpeg.

## Deploy on Streamlit Community Cloud

1. Upload all files in this repository to GitHub.
2. Open Streamlit Community Cloud.
3. Select this GitHub repository.
4. Set the main file to `app.py`.
5. Deploy.

### Files

- `app.py` — main Streamlit application
- `requirements.txt` — Python dependencies
- `packages.txt` — system package dependency

## Supported video formats

MP4, MOV, MKV, AVI

## Supported audio formats

MP3, WAV, M4A, AAC
